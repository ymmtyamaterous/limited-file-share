# UI / 画面設計書

## 1. 概要

- **フレームワーク:** React + TanStack Router
- **UIコンポーネントライブラリ:** shadcn/ui
- **スタイリング:** Tailwind CSS
- **テーマ:** ライト/ダークモード切替対応

---

## 2. 画面一覧

| 画面名 | パス | 説明 |
|--------|------|------|
| ホーム（共有作成） | `/` | ファイル/テキストのアップロード・共有作成フォーム |
| 共有完了 | `/share/complete` | 共有URL・削除トークン表示 |
| コンテンツアクセス | `/s/:shareId` | パスキー入力とコンテンツ表示 |
| Not Found | `*` | 404エラーページ |

---

## 3. 各画面詳細

### 3.1 ホーム画面（共有作成）

**パス:** `/`

**目的:** ユーザーがファイルまたはテキストをアップロードして共有を作成する

> **参考デザイン:** [`docs/agent/home-design.html`](../home-design.html)
> HTMLプロトタイプとして実装済み。ビジュアル・インタラクション（タブ切り替え・D&D・ダークモード・パスキー表示トグル）の実装時はこのファイルをベースにすること。

#### レイアウト

```
┌─────────────────────────────────────────────┐
│ [ヘッダー: サービス名 + ダークモード切替]       │
├─────────────────────────────────────────────┤
│                                             │
│  Limited File Share                         │
│  ファイルやテキストを簡単に共有              │
│                                             │
│  ┌──────────────────────────────────────┐   │
│  │ [タブ: ファイル | テキスト]            │   │
│  │                                      │   │
│  │ <ファイルタブ選択時>                   │   │
│  │  ┌────────────────────────────────┐  │   │
│  │  │  ドラッグ＆ドロップ             │  │   │
│  │  │  またはクリックでファイル選択   │  │   │
│  │  │  (最大 50MB)                   │  │   │
│  │  └────────────────────────────────┘  │   │
│  │  選択済みファイル: example.pdf (2MB)  │   │
│  │                                      │   │
│  │ <テキストタブ選択時>                  │   │
│  │  ┌────────────────────────────────┐  │   │
│  │  │ テキストまたはコードを入力...  │  │   │
│  │  │                                │  │   │
│  │  └────────────────────────────────┘  │   │
│  │                                      │   │
│  │  パスキー: [__________________]       │   │
│  │  有効期限: [▼ 1日]                   │   │
│  │  ダウンロード回数制限: [__] (省略可)  │   │
│  │                                      │   │
│  │  [共有を作成する]                     │   │
│  └──────────────────────────────────────┘   │
│                                             │
└─────────────────────────────────────────────┘
```

#### コンポーネント

| コンポーネント | 説明 |
|--------------|------|
| `ShareForm` | 共有作成フォームのルートコンポーネント |
| `FileUploadTab` | ファイルアップロードのドラッグ＆ドロップUI |
| `TextShareTab` | テキスト入力Textarea |
| `PasskeyInput` | パスキー入力フィールド（マスク表示） |
| `ExpirySelect` | 有効期限選択ドロップダウン |
| `DownloadLimitInput` | ダウンロード回数上限の任意入力 |

#### 有効期限の選択肢

| 表示ラベル | 値（秒） |
|-----------|---------|
| 1時間 | 3600 |
| 1日 | 86400 |
| 7日 | 604800 |
| 30日 | 2592000 |

#### バリデーション

- ファイル/テキストのいずれか必須
- ファイルサイズ: 最大50MB
- テキストサイズ: 最大1MB
- パスキー: 4文字以上必須
- ダウンロード回数制限: 入力する場合は1以上の整数

```
│  └──────────────────────────────────────┘   │
│                                             │
```

#### コンポーネント

| コンポーネント | 説明 |
|--------------|------|
| `ShareCompleteCard` | 共有完了情報カード |
| `CopyButton` | クリップボードコピーボタン |
| `QRCodeModal` | QRコードモーダル |
| `DeleteTokenWarning` | 削除トークンの警告表示 |

- このページはフロントエンドのstate経由でデータを受け取る（URL queryパラメータは使用しない）

### 3.3 コンテンツアクセス画面

**パス:** `/s/:shareId`

**目的:** パスキーを入力してコンテンツにアクセス・閲覧・ダウンロードする

#### フロー

```
URLアクセス
  │
  ▼
メタデータ取得（share.getMeta）
  │
  ├─ NOT_FOUND → エラー表示（「この共有は存在しないか期限切れです」）
  │
  └─ 成功 → パスキー入力フォーム表示
              │
              ▼
            パスキー送信（share.unlock）
              │
              ├─ UNAUTHORIZED → エラー表示（「パスキーが正しくありません」）
              │
              └─ 成功 → コンテンツ表示
```

## 4. ルーター構成（TanStack Router）

```
__root.tsx          ← ヘッダー・テーマプロバイダー・共通レイアウト
```

## 6. 状態管理方針

- サーバー状態: TanStack Query（oRPCクライアント経由）を使用
- フォーム状態: React Hook Form + Zod バリデーション
- 共有完了データ（URLと削除トークン）: TanStack Router の `navigate` で `state` として渡す
  - ページリロード時は再取得不可のため、リロード時は作成ページにリダイレクト

---

## 7. レスポンシブデザイン

- モバイル（〜768px）: シングルカラムレイアウト
- タブレット以上（769px〜）: コンテンツを中央寄せ（最大幅 640px）
- ファイルのドラッグ＆ドロップはデスクトップのみ有効、モバイルはタップで選択

---

## 8. アクセシビリティ

- パスキー入力はデフォルトでマスク表示、表示切替ボタンあり
- コピー成功時はトースト通知（sonner）で確認メッセージを表示
- ローディング中はスケルトンコンポーネントを表示
- エラー時はインラインエラーメッセージを表示
